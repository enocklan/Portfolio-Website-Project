# Enock Langat — Personal Portfolio Website

A responsive personal portfolio website built to introduce myself, showcase my web development skills, display my projects, and provide a way for visitors to get in touch with me.

## 🌐 Live Website

[Visit My Portfolio](https://enocklan.github.io/Portfolio-Website-Project/)

## 📖 About The Project

This portfolio website was created as part of my journey into web development.

It provides information about me, my technical skills, projects I have worked on, and ways to contact me.

The project focuses on creating a clean, simple, responsive, and user-friendly interface using fundamental web technologies.

## ✨ Features

- Responsive design for desktop, tablet, and mobile devices
- Personal introduction and About Me section
- Dynamic Skills section
- Dynamic Projects section
- Project descriptions and technologies used
- Contact section
- Email contact link
- GitHub profile link
- Smooth navigation between sections
- Responsive navigation menu
- Clean and minimal dark-themed interface

🚀 How to Run It Locally

To run this project locally on your machine, follow these simple steps:

1. Clone the repository
git clone https://github.com/enocklan/Portfolio-Website-Project.git
2. Navigate into the project directory
cd Portfolio-Website-Project
3. Open the project

Open the index.html file directly in your preferred web browser, or use a local development server extension such as Live Server in VS Code.
